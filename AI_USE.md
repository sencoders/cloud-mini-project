# AI assistance and verification

**OpenAI Codex** assisted with reading ASSIGNMENT.pdf; designing, generating and
editing infrastructure, Python code, tests, scripts, prompts, CI workflows and
documentation; diagnosing failures; calculating costs/SLOs; typesetting the report;
and conducting the publication audit. This disclosure does not claim the student
independently authored AI-assisted work. The required personal handwritten
reflection must be written and supplied by the student, not generated by Codex.

**Ollama phi3.5:latest** is the assignment's teacher. It generated the actual
labelling/teacher-validation targets with temperature 0 and seed 42, using the
committed teacher prompt. Those replies are retained exactly as generated.
Codex did not supply or manually correct teacher labels. Only teacher replies
from the first 1,500 cleaned records were training targets; validation labels
were used for evaluation only. No paid inference API is called by the pipeline.

Verification of the assistance used:

- Task 1: five-command smoke test, concurrent Kubernetes workers, source-ID
  accounting, deterministic cleaning, restart-safe checkpoint comparisons,
  S3 byte read-back and SHA-256 verification.
- Task 2: CPU-only smoke/full training, prompt/padding/EOS loss-mask tests,
  repeated-smoke weight/loss comparisons, artifact checksum/reload checks and
  actual all-100-record evaluation of teacher, untrained student and trained V1.
- Task 3: real Docker build and 50 sequential requests at 1 CPU/1 GiB, cgroup
  memory/OOM counters, health/readiness tests, output/schema/header comparisons
  and the required fault-injection error.
- Task 4: actual Kubernetes state, download logs and timestamps, unchanged Locust
  tests, successful-response header counts, rollout/rollback, recovery and HPA

- Tasks 5–7: unchanged packet simulator, boundary/unit tests, original resource
  and Locust measurements, Decimal cost arithmetic, integer error-budget checks,
  local Release archive/member verification, actual evaluator execution and
  scorer gate pass/failure checks. The local suite recorded 129 passing tests
  and one optional S3 test skipped; Ruff and Gitleaks were run.
- Publication: all reachable historical blobs and paths were inspected, including
  raw/base64 matching of actual local credentials/private keys, forbidden artifact
  checks and configured Gitleaks. Its only exception is the exact public Docker
  GPG signing fingerprint; initial diagnostics and scope are retained.

No prediction is repaired or replaced with gold labels. Measured results, failed
thresholds, assumptions and unexecuted checks are identified in the reports.
Publication and remote CI are reported only after verification, separately from
historical local-only evidence. AI suggestions are not treated as test results.

its first configuration failure is retained. Hidden results and full marks are
